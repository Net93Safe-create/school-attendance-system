# School Attendance System

## Project Overview

This project proposes an electronic attendance system for a secondary school. It aims to make attendance records easier to manage than paper registers.

Problem Statement

Paper attendance registers can be difficult to organise, take time to check, and make it challenging to prepare attendance reports.

## Proposed Solution

The proposed system will allow authorised teachers to record students as present, absent, or late and generate attendance summaries.

## Project Objectives

* Record student attendance electronically.
* Organise attendance records by class and date.
* Generate attendance reports.
* Reduce mistakes and time spent managing paper registers.
